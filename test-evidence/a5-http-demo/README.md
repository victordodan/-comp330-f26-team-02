# Packaged HTTP Demo — Recorded Evidence

Generated by an actual Codex rehearsal, not prefilled expectations. All data is
synthetic. No cookies, authentication tokens or real student records are stored.

- `environment.json`: source context, runtime versions, hashes and observed totals.
- `build-summary.txt`: extracted lines from the successful local Maven log.
- `workflow.jsonl`: 36 successful HTTP checks, including body/state assertions.
- `restart-state.json`: synthetic stored record/ETag used for restart comparison.
- `restart.jsonl`: 5 successful HTTP checks after a full JVM stop/start.
- `repeat.jsonl`: 36 successful HTTP checks against the existing database.
- `transport-failure.jsonl`: intentional stopped-server control, expected FAIL/exit 1; not an application defect.

JSONL final PASS requires both status and body assertions to finish successfully.
A response row alone is not proof all later assertions passed. Request IDs and
timestamps are observed values; replaying the script produces new ones.

The executable is delivered by companion PR #97; its SHA256 is recorded in
`environment.json`. Procedure and limitations are in
[demo-script.md](../../docs/release/demo-script.md).

The build ran with Temurin JDK 17 after workspace setup. Initial JRE-only/proxy
setup failures were resolved locally without application changes. Build summary
is from the successful run, not those environment setup attempts. This evidence
is not final A5-tag verification, student acceptance or security clearance.
